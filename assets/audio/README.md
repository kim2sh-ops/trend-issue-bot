# 릴스 배경음

이 폴더에 **저작권프리 음원 파일 1개**(`.mp3` / `.m4a` / `.wav`)를 넣으면
릴스 렌더 시 자동으로 배경에 깔립니다 (볼륨 16%, 페이드 인/아웃, 영상 길이에 맞춰 루프).

파일이 없으면 릴스는 무음으로 나갑니다.

## 무료 음원 구하는 곳 (상업적 사용 가능)

- **Pixabay Music** — https://pixabay.com/music/ — 출처 표기 불필요, 가장 간단
- **YouTube 오디오 보관함** — studio.youtube.com → 오디오 보관함 → "저작자 표시 필요 없음" 필터
- **Free Music Archive** — https://freemusicarchive.org — 라이선스별로 다름, CC0/CC-BY 확인

차분한 로파이/앰비언트 계열이 카드뉴스 릴스에 잘 어울립니다. 30초 이상이면 충분 (루프됨).

## 파일명

아무거나. 여러 개 넣으면 알파벳 순 첫 번째만 사용합니다.
